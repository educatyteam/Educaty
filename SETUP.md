# Educaty — подключение формы к Telegram

Готовый бот: **@educatyleads_bot**. Дальше — 4 коротких шага.

⚠️ **Безопасность**: токен бота нельзя класть прямо в код сайта (в `<script>`). Любой, кто откроет «view-source» страницы, получит токен и сможет писать в ваш бот / удалить его. Поэтому токен живёт **только** в переменных окружения Cloudflare Worker, а сайт ходит к воркеру.

---

## Шаг 1 · Получить `chat_id` (куда бот будет писать)

Бот может писать вам **в личку** или **в группу**. Выберите вариант:

**A. В личку (самый простой):**

1. Откройте бота в Telegram: <https://t.me/educatyleads_bot>
2. Нажмите **Start** (или отправьте `/start`).
3. После этого откройте в браузере:
   ```
   https://api.telegram.org/bot8647124207:AAE0aaDjGo96xoGPeSjbFC2J9tm2n2-5JeU/getUpdates
   ```
4. В ответе найдите `"chat":{"id": 123456789, ...}` — это и есть ваш `chat_id` (большое число).

**B. В группу/канал (если хотите чтобы туда могли смотреть несколько человек):**

1. Создайте группу / канал в Telegram.
2. Добавьте бота `@educatyleads_bot` в группу. Для канала — сделайте его администратором с правом писать.
3. Напишите в группе любое сообщение (например `/start@educatyleads_bot`).
4. Откройте: `https://api.telegram.org/bot8647124207:AAE0aaDjGo96xoGPeSjbFC2J9tm2n2-5JeU/getUpdates`
5. Найдите `"chat":{"id": -1001234567890, ...}` — для групп / каналов ID начинается с минуса.

Сохраните `chat_id` — он понадобится в шаге 3.

## Шаг 2 · Развернуть прослойку (Cloudflare Worker, бесплатно, ~3 минуты)

1. Зайдите на <https://dash.cloudflare.com> → **Workers & Pages** → **Create application** → **Create Worker**.
2. Назовите, например, `educaty-leads`. Нажмите **Deploy** (создастся пустой воркер с дефолтным кодом).
3. Откройте созданный воркер → **Edit code**.
4. Удалите весь дефолтный код. Скопируйте полностью содержимое файла `lead-forwarder.js` из этой папки → вставьте в редактор Cloudflare.
5. **Save and Deploy**.
6. Скопируйте URL воркера сверху страницы — будет вида `https://educaty-leads.<ваш-юзер>.workers.dev`.

## Шаг 3 · Прописать секреты в Worker

В воркере перейдите **Settings → Variables** (или **Variables and Secrets**) → **Add variable**. Добавьте по одной:

| Имя | Значение | Тип |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | `8647124207:AAE0aaDjGo96xoGPeSjbFC2J9tm2n2-5JeU` | Secret |
| `TELEGRAM_CHAT_ID` | (значение из шага 1) | Secret |
| `ALLOWED_ORIGIN` | `https://educaty.com,https://www.educaty.com` (через запятую, без пробелов) | Plaintext |
| `AMOCRM_WEBHOOK_URL` | (оставьте пустым, если amoCRM не нужен) | Secret |

> Для боевой защиты — отметьте первые две как **Secret** (Cloudflare не покажет их после сохранения).

Нажмите **Deploy** ещё раз, чтобы переменные подхватились.

---

## Шаг 4 · Связать сайт с воркером

В `index.html` найдите строку (примерно середина `<script>` ближе к концу):

```js
const LEAD_ENDPOINT = "https://YOUR-LEAD-FORWARDER-URL.workers.dev";
```

И впишите туда URL вашего воркера из шага 2. Сохраните и задеплойте сайт.

## Проверка

1. Откройте лендинг.
2. Заполните форму «Записаться на мастер-класс» (имя + телефон) → «Подать заявку».
3. В выбранный чат (вы лично или группа) бот пришлёт сообщение в течение 1–2 секунд:
   ```
   🎓 Заявка на мастер-класс
   Имя: ...
   Телефон: ...
   Форма: ai-creator-masterclass
   Страница: https://educaty.com
   ```

Если не пришло:
- Откройте Cloudflare → ваш воркер → **Logs (Live)** — увидите HTTP-запрос от сайта и ошибку (если есть).
- Проверьте, что в `ALLOWED_ORIGIN` есть домен, с которого открыт лендинг.
- Проверьте, что вы реально нажали Start в боте (без `/start` Telegram не даст боту писать вам в личку).

## После того как всё работает

🔄 **Поверните токен**: токен бота побывал в чате со мной и в этом файле в репозитории. Это нормально на этапе настройки, но для боевого использования:

1. В @BotFather → `/mybots` → `@educatyleads_bot` → **API Token** → **Revoke current token**.
2. Получите новый токен.
3. Замените `TELEGRAM_BOT_TOKEN` в Cloudflare → **Deploy**.
4. Удалите старый токен из этого файла и из истории git (или просто перепишите этот файл — старый коммит может остаться в истории, поэтому ротация = единственный надёжный способ).

## amoCRM (опционально, на потом)

Когда захотите — добавьте в **AMOCRM_WEBHOOK_URL** входящий вебхук из amoCRM:

1. amoCRM → Настройки → Интеграции → API → **Входящие вебхуки** → создать.
2. URL формы скопируйте в переменную воркера.
3. В правилах сопоставления привяжите поля: `contact[name]`, `contact[phone]`, `lead[name]`, `lead[tags]`. Воркер уже шлёт эти поля.

После этого заявки будут падать одновременно в Telegram и в воронку amoCRM.
